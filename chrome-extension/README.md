# SkillBridge AI — Form Auto-Fill Chrome Extension

## Quick Install (Developer Mode — 20 Seconds)
1. Open Chrome and go to `chrome://extensions/`
2. Enable **Developer mode** (toggle at top right).
3. Click **Load unpacked** and select this `chrome-extension/` folder (or the extracted downloaded zip).
4. Open **SkillBridge Student Portal** (`http://localhost:3000/student`) — your profile automatically syncs!
5. Open any external job form (Greenhouse, Lever, Ashby, SmartRecruiters, Workday, Zoho, TCS), click the SkillBridge extension icon, review your pre-filled answers, click **Auto-Fill Form on This Tab**, verify highlighted fields (and attach your PDF resume), and submit safely yourself.
